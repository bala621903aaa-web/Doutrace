# Hermes 建议与当前实现核对

核对日期：2026-10-04（Asia/Shanghai）。本文是用户提供建议的评估，不改变 P1 真实验收条件或旧扩展保留范围。

## 已经变化的事实

- `sent-time` 已在最终实现取得 16 条不同平台 ID 的真实完整时间证据，字段 10 毫秒转换与官方页面 Date 精确一致；详见 [P1-OFFICIAL-TIME-MAPPING.md](P1-OFFICIAL-TIME-MAPPING.md)。四个候选现在确实按同一消息比较；扩展与字段 10 同分钟的事实保留为计数，官方显示链路决定字段来源。诊断报告保持脱敏，不打印原始 ID 或正文。
- 最终冻结实现的新鲜 chain 和重启 recovery 已通过，不需要复活不完整的旧报告。旧 recovery 的 `disjoint` 不能替代本轮真实的同游标控制页、输出游标和下一页对账。
- 桌面终点已经使用成功协议响应的明确 `has_more=false`，加同输入游标重读及 ID/索引顺序一致。根扩展 `douyin-dom.ts` 的 DOM 终点占位实现不属于这个 P1 路径。少于 limit、空页、索引变小或游标停滞不能单独成为完整历史终点。
- 当前独立浏览器配置及应用数据根已存在，正常登录由用户完成。正式桌面适配器、SQLite 存储与档案界面仍属 P2～P5，尚未完成。

## 建议采用的后续改进

全文件 SHA 失效是保守机制，确实会把无关注释或实现修改与行为变化一并处理。后续可改为每个结论记录明确依赖及变更影响；还应建立本机 Git 基线或可恢复源码快照，使历史实现可以重建。当前已冻结源码并完成一轮新鲜证据，不在收尾期间改失效规则来迁就旧 pass。

细粒度依赖应包含真实共享路径，不能只绑定一个映射版本。例如 `sent-time` 使用 `history-transport` 提供的初始化/历史消息、账号身份和实际加载脚本；修改这些读取语义仍可能使时间结论失效。建议最小依赖如下：

| 结论 | 必须覆盖的行为依赖 |
|---|---|
| real-channel | 请求/响应匹配、传输、wire/包裹层解码、HTTP 与业务状态 |
| identity | 自账号来源、选中会话读取、请求/消息会话及短 ID 校验 |
| platform-message-id | 64 位 decoder、消息成员归属和去重 |
| three-pages-no-scroll | 请求更新与游标续传、消息新增/顺序、前后及跨页位置读取 |
| sent-time | 上述身份/消息来源、当前窗口合并、官方脚本散列、copy DOM 归属、日期/字段/单位/顺序验证 |
| history-end | 成功响应的结束字段、选定目标、同游标重读及一致性验证 |
| cursor-recovery | 检查点、控制页、版本身份、重启请求及下一页对账 |
| message-semantics | 类型/内容/显式引用解码和必需样本判定 |

P2 产品层修改不必改变已经冻结的 P1 验证器；若关键协议或传输行为改变，补验受影响结论。离线回放只能证明新实现如何解释旧交换，不能新造当时未采集的页面时间、选中身份、无滚动或重启控制页证据。

产品文档应更新为桌面方案：应用拉起独立浏览器配置，用户正常登录，按平台 ID 建立本机档案。SQLite 事务保存消息与游标、附件结果独立记账，以及实际 Electron 中原生模块与便携包浏览器路径冒烟，都应列入 Luna 后续实现和验收。

## 当前不执行的范围变更

用户现有要求是保留旧扩展，P1 由 Sol 完成，后续交 Luna。因此现在不移动根扩展目录、不改其构建入口，也不在 P1 汇总通过前编写产品存储/采集层。

原始认证请求落盘与现有 P1 隐私边界冲突。需要离线样本时应另外设计仅限选定响应的最小结构、剔除认证及无关会话、限制本机保存并明确用途；不能直接保存浏览器完整请求帧。本次仍只保留脱敏真实报告及本机最小恢复检查点。

本轮还发现并修复两个状态记录错误：有界上限仍 `has_more=true` 时 reason 未转成 `page-limit`；后续页到达明确终点时赋值丢失已累计的会话身份。旧报告实际 7 页/325 条及终点 25 条重读已获得，但身份为 null，保持未通过，没有在汇总层强行提升。修复后用 `p1-sol-final-20261004` 新 suite 完成全部真实重验；同窗口批量主序列减少手工操作，重启恢复与短会话终点独立执行，终点身份及重读均通过。最终验收八项 pass、代码版本匹配、P2 门开放，见 [P1-SOL-RECHECK.md](P1-SOL-RECHECK.md) 和 [验收汇总](P1-ACCEPTANCE-SUMMARY.md)。
