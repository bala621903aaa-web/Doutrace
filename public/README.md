# 抖音私聊导出 · 0.2.0

## 安装

1. 解压发布压缩包。
2. 在 Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 打开“开发者模式”，点击“加载已解压的扩展程序”，选解压后的 `douyin-chat-archive` 文件夹。
4. 登录抖音网页版并打开一个人的私聊，再点击工具栏里的扩展图标。工具会在当前聊天页右侧打开悬浮面板，不会新开工具标签页；面板可以拖动或收起。

## 当前状态

本版本已验证抖音网页版聊天行、会话标题、本人/对方标记和消息列表滚动方式；读到图片后会保存页面可见图片数据。语音只在页面提供可读的 `audio` 源时尝试保存，并保留原始音频格式；当前目标私聊没有可验证的语音消息，因此不承诺覆盖所有语音格式或能在每种播放器中播放。历史终点没有可确认的页面标记，加载无变化时会报告“停滞”，不会宣称完整导出。

采集不触发发消息或切换会话。登录信息不会写入导出文件。ZIP 包含 `messages.json`、`media/`、`index.html` 和 `export-report.json`。完全删除本机档案无法撤销。点击扩展图标可以再次显示或收起当前页的悬浮面板。
